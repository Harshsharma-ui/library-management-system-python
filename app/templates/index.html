Granthify

A robust, cyber-hardened Library Management System built with Python Flask, SQLAlchemy ORM, and modern web defenses. Designed for academic institutions requiring strict security, role-based controls, and automated circulation management.

Browse Books Sign In Student Registration
Zero-Trust Ready

Engineered with defensive security, rate-limiting lockout, and complete activity auditing.

Adaptive Bcrypt Hashing

User passwords are salted and hashed using the adaptive Blowfish-based Bcrypt algorithm (work factor 12) protecting credentials against GPU brute-force and rainbow table attacks.

Account Lockout & Limiting

Intrusion prevention triggers an automatic 15-minute temporary lockout after 5 consecutive failed login attempts, recorded into audit logs with the client's IP address.

SQL Injection Immunity

Every database query is orchestrated through SQLAlchemy ORM with strictly parameterized queries, isolating user data inputs from SQL execution plans.
